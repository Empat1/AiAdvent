# 🔥 День 4. Эксперимент с Temperature на DeepSeek API

**Дата:** 07.09.2026
**Модель:** `deepseek-v4-flash`
**Задача:** придумать 5 концепций кофейни рядом с кальянной и водочной
**Температуры:** `0.0`, `0.7`, `1.2`

---

## 🎯 Условие задачи

> Придумай 5 идей для кофейни, которая будет успешно работать рядом с кальянной и водочной.

**Почему эта задача подходит:**
- Нет «правильного» ответа — можно сравнивать креативность
- Требует понимания контекста (соседство с алкогольными заведениями)
- Достаточно длинный ответ, чтобы увидеть разницу в стиле
- Повторяемость — можно запустить 3 раза и сравнить

**Характерные черты:**
- ✅ **Единый шаблон** для всех 5 идей: Концепция → Фишки → Почему работает
- ✅ **Общая идея в конце** — связывает всё в единую стратегию
- ✅ Все названия на русском, описательные
- ✅ Нет рискованных идей — все концепции «безопасные»
- ⚠️ Предсказуемые решения: «детокс», «ночная», «транзит» — типичный набор

**Вердикт:** Идеально для бизнес-плана. Скучно для брейншторма.

**Вердикт:** Золотая середина. Креативно, но ещё применимо на практике.

**Концепции:**

- ✅ **Рискованная идея**: «Бар-кофейня» — играет с алкоголем, а не противопоставляет ему

- ⚠️ **Опечатка**: «заседаниеи» — признак высокой температуры
- ⚠️ Последняя концепция обрывается на полуслове — модель «увлеклась»

**Вердикт:** Максимум идей и деталей, но есть шум. Требует фильтрации.
