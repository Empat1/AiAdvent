# DeepSeek Reasoning API Client

Production-ready Python-клиент для работы с **DeepSeek Reasoner (R1)** через OpenAI-совместимый API. Реализует безопасную аутентификацию, структурированное логирование, обработку ошибок и извлечение цепочки рассуждений модели.

## ✨ Особенности

- **Поддержка режима рассуждения**: Извлечение как финального ответа (`content`), так и скрытой цепочки мыслей (`reasoning_content`)
- **Безопасное управление секретами**: Загрузка ключей из `.env` через `python-dotenv`, никаких хардкодов
- **Комплексная обработка ошибок**: Раздельная обработка rate limits, таймаутов, сетевых и API-ошибок с информативным логированием
- **Типизация**: Полные type hints и docstrings для всех публичных функций
- **Переиспользуемая архитектура**: Фабричный паттерн для клиента, чистое разделение ответственности
- **Структурированные логи**: Форматированный вывод через `logging` вместо `print`

## 📋 Требования

- Python ≥ 3.10
- Пакеты: `openai>=1.60.0`, `python-dotenv`
